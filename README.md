# CIS Program Director Guide

The how-to guide Bossier Parish Community College's Program Directors use to review the courses in their programs in the Course Inventory Sweep (https://sweep.joebrownlee.com). It is a static page with its screenshots. It stores nothing and sends nothing.

The screenshots show sample entries (Jane Doe, jdoe@bpcc.edu), never real submissions. `index.html` is built from the guide's source in the Sweep's rebuild kit, kept by the Office of Academic Affairs. Edit the source and rebuild rather than editing this file by hand.
